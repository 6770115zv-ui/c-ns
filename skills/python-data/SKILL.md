# Python and data analysis

## תהליך
1. בדוק את מבנה הקלט: שמות עמודות, טיפוסים, encoding, גודל, ערכים חסרים וכפילויות.
2. שמור עותק מקור; אל תדרוס את הקלט אלא אם התבקשת במפורש.
3. בחר ספריות שכבר קיימות בפרויקט. אם נדרשת התקנה, הסבר למה והשתמש בגרסה תואמת.
4. בדוק הנחות, יחידות, אזורי זמן, מפרידים וערכים חריגים.
5. חשב תוצאות באופן שניתן לשחזור; העדף קוד קצר וברור על חישוב ידני.
6. אמת סכומים, ספירות וטווחים מול נתוני המקור.
7. שמור תוצר עם encoding ושמות עמודות ברורים, וסכם שיטה, תוצאות ומגבלות.

## כללים
- לעולם אל תציג מתאם כסיבתיות.
- ציין גודל מדגם ונתונים חסרים כשהם משפיעים על המסקנה.
- אל תעגל לפני החישוב הסופי.
- בדוחות או גרפים, תן כותרות, יחידות ותוויות קריאות.
