# UX and accessibility

## תהליך
1. זהה את המשימה המרכזית ואת מסלול המשתמש העיקרי.
2. בדוק היררכיית מידע, labels, שפה, כיווניות RTL/LTR ו־responsive breakpoints.
3. ודא שלכל פעולה יש feedback ברור: loading, success, error ו־disabled.
4. אפשר ניווט מקלדת מלא, focus visible, שמות נגישים וניגודיות מספקת.
5. שמור על state בעת שגיאה; אל תאבד טקסט או עבודה שלא נשלחה.
6. בדוק dialog, overflow, scrolling, touch targets והתנהגות במסכים קטנים.
7. בצע בדיקת usability קצרה לפי תרחישים מוגדרים.

## כללים
- אל תסתמך על צבע בלבד כדי להעביר משמעות.
- אל תשתמש באנימציה מהירה או מהבהבת בלי צורך.
- אל תסתיר שגיאות מאחורי הודעות כלליות.
