# Frontend development

## תהליך
1. קרא את מבנה ה־DOM, ה־CSS, ה־JavaScript, ה־assets וה־build setup הקיימים.
2. שמור על שפה חזותית עקבית, RTL/LTR לפי התוכן, ו־responsive layout.
3. בנה סמנטיקה נכונה: headings, labels, buttons, keyboard navigation ו־focus states.
4. בדוק loading, empty, error, success ו־disabled states.
5. השתמש ב־textContent או DOM APIs בטוחים לתוכן לא מהימן; אל תכניס input של משתמש ל־innerHTML.
6. בדוק מסכים צרים, ניגודיות, reduced motion ו־keyboard-only.
7. הרץ smoke tests ובדוק console/network errors אם סביבת הדפדפן זמינה.

## כללים
- אל תוסיף framework כבד לדף סטטי בלי צורך.
- צמצם dependencies חיצוניות והצמד גרסאות כשאפשר.
- אל תציג כפתור שאינו מבצע את הפעולה הכתובה עליו.
